# TV, live audio and fixture broadcast updates

- Native Android package 1.1.0 supports the Android TV/Google TV/Fire TV launcher, optional touchscreen, a 320×180 launcher banner, TV device detection, landscape layout, D-pad and media keys. Hardware volume buttons retain system media-volume behavior.
- `/tv-app` provides an install path and explicit TV layout switch. Samsung/LG TVs use their browser; the Android APK is not a Tizen/webOS store package. No claim of universal app-store installation or testing on every TV model.
- Site remote navigation now works inside fullscreen players, popovers and dialogs. Back closes the current dialog first. Form fields/range inputs keep native arrows. Hidden controls are revealed before D-pad focus moves.
- Live audio uses bounded persisted levels, volumechange synchronization, 5% +/- controls, a fine slider and mute that restores the last audible level. Browsers that reject programmatic volume expose hardware-volume guidance.
- Google Cast prefers public CORS proxy media endpoints and retries compatible sources of the same channel. ClearKey and raw MPEG-TS sources are excluded from the default Cast receiver. The connection panel displays receiver volume, mute and the connected TV name. AirPlay/native remote playback remain capability-detected. These paths require compatible receivers, codecs and media permissions; no unauthorized access or DRM circumvention is added.
- The football agenda automatically consults the public Futebol na TV guide for today/tomorrow in Brasília, alongside ESPN, TheSportsDB and EPG. Only matching teams, the same local date and kickoff within 45 minutes may contribute channel names. Different age/gender categories are kept distinct. Names only become watch links when an available matching channel exists locally. Requests are deduplicated and cached for ten minutes, with independent provider fallbacks.
- The TV sports shelf uses compact horizontal tickets, compact dates and collapsible alternate channels. Standings and the full agenda remain on the football page.
- Mobile keeps only floating search plus the existing bottom glass dock. The horror row is now “Mais terror na sua noite”, with a locally served OFL Bebas Neue font and subtle blood-colored details; editorial filler text was removed.

Validation includes unit tests for volume, receiver candidate selection, TV key codes and broadcast identity, strict diagnostics in changed modules, production build, browser smoke with generated test media, and Android build/launcher verification. A physical Chromecast/AirPlay receiver or TV is not available in this environment, so hardware pairing remains a device-dependent validation limit.
